# QartNET — Qart Hadasht Network for Engineering & Technology

> **QartNET** is a collaborative platform built for the academic community of the National Engineering School of Carthage (ENICarthage), focused on digital technologies and engineering innovation.
---

## Overview

QartNET aims to create a **centralized academic ecosystem** where students and faculty can collaborate, share knowledge, and manage engineering projects in a structured and scalable environment.

The platform combines the power of:

* an **academic social network**
* a **Git-based project hosting system**
* and a **collaborative project management environment**

By integrating these components into a single platform, QartNET aims to improve knowledge sharing, project visibility, and technical collaboration within the institution.

---

## Key Features

*  **Academic Social Network**
  User profiles, publications, groups, and real-time communication enable structured and continuous interaction between students and faculty.

*  **Integrated Git Hosting**
  Native repository management with support for version control operations such as push, pull, and commit history, tailored to an academic context.

*  **Project Management**
  Projects are organized into phases, tasks, and milestones, allowing teams to track progress and collaborate effectively.

*  **Forum System**
  A structured discussion space with categories and tag-based filtering to facilitate technical exchanges and knowledge sharing.

*  **Code Review System**
  Support for structured feedback from instructors and peers, ensuring traceability and quality in project development.

*  **Admin Backoffice**
  Dedicated tools for user management, content moderation, and overall platform supervision.

---

## Architecture (High-Level)

QartNET follows a **scalable layered architecture**:

* **Frontend:** Angular 21+
* **UI Library:** PrimeNG 21
* **Styling:** Tailwind CSS v4
* **Backend:** Spring Boot (REST API)
* **Databases:** PostgreSQL (+ MongoDB)
* **Version Control Integration:** Git
* **Real-time Communication:** WebSockets
* **Build:** Maven (backend) · Angular CLI (frontend)
* **Deployment:** Cloud-ready, scalable infrastructure

## Vision

QartNET is designed to evolve into a **full academic collaboration ecosystem** for engineering and digital innovation. Once the platform reaches a stable and mature stage, contributions will be opened to students of the institution. This initiative aims to provide a real-world development environment where students can apply their technical skills, gain practical experience, and learn to collaborate within a professional framework.

Contributors will work on the platform under the guidance of alumni and experienced members, fostering mentorship, knowledge transfer, and a strong engineering culture within the academic community.
